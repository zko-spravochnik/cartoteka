КАРТОТЕКА — ОТЧЁТ: РЕЛИЗ v1.0.0.1 (2026-10-31)

1. Г2 БЕЗ РУЧНОГО ВВОДА. В редакторе очереди поле Г2 только для тапа: два окна подряд (главная категория → подкатегория), в обоих [ ⬅️ Назад ].
   Готовый текст встаёт в Г2, сайт пересчитывает Г1, Г17, Г19 (метка «🔗» и лог).
2. СЕРВЕР — ГЛАВНЫЙ ПО СВЯЗКЕ. Категория из Г2 ищется в categories.json (устойчиво к регистру/пробелам/тире). Если категория изменилась, а Г1 не из неё,
   сервер сам выдаёт новый ID, пересобирает маски, переносит строку между секциями и проверяет результат (старого ID нет, новый один). Иначе откат.
   Новые ошибки: bad_folder, verify_failed. Причина дефекта v1.0.0.0: ручной ввод Г2 мог не совпасть с каталогом, Г1 оставалась 1107, строка менялась на месте.
3. Версия «Релиз v1.0.0.1» (index.html, манифест, кэш PWA cartoteka-v1.0.0.1 / test-cartoteka-v1.0.0.1, dbEpoch 2026-11-01-v1001-cache-reset, шлюз).
4. README: «Библия скриптов» (RABOTA_SKRIPTOV.txt, раздел 4.9).
